# Dependências Eclipse/Palladio do Retriever

Para desenvolvimento e execução real do Retriever, ainda é necessário configurar
manualmente:

- Eclipse 2022-12 Modeling Tools;
- Java Development Kit 17;
- PCM Nightly;
- Fluent API Model Generator;
- Xtend IDE;
- Retriever via update site;
- importação dos projetos no Eclipse;
- criação de uma Run Configuration do Retriever.

O build Maven valida parte do ambiente, mas não substitui a configuração
Eclipse/Palladio. O Eclipse não foi instalado nesta etapa.
